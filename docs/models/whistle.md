# Whistle

> **Stub — pending Stage 8 (porting-8-ship).** This page exists so
> `catalog/whistle.json` can be seeded at Stage 6. Prose, accuracy and
> speed tables are rendered from the catalog at ship time.

Whistle (`Cactus-Compute/whistle`, Apache-2.0) is a ~55M-parameter
encoder-decoder ASR model for English, German, French, Spanish, Italian,
Dutch and Polish, with a hard 30 s per-pass audio cap and word-level
timestamps. See `docs/porting/families/whistle.md` for the porting record.
