# Licence texts

One directory per licence text shipped to the HF repos. `generate.py` copies
`LICENSE` into every repo and builds its `NOTICE` from the directory's `NOTICE`
(the attribution line the licence mandates, when it has one) plus a generated
statement of how the files were modified. The directory is the catalog
record's `license.text`, or else its `license.name`, or else its
`license.spdx`.

Texts are reproduced verbatim from the sources below. The two published only
as web pages carry a short header naming the page and the retrieval date.
